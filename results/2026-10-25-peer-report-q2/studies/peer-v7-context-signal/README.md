# V7 fixed-average / same-number context-function study

Read FINAL_REPORT.md after completion. Live state is run_state.json; source
and parameter provenance are independent of any final interpretation.

This separately authorized native-Dolos follow-up uses the existing JSON/tool
anchor and two fixed wordings. It does not repeat behavioral hint-following,
search new formats or components, train models, or access the A5000.

1. prepare.py reserves digit-role-balanced, disjoint discovery/confirmation
   banks and records exact serialized prompt/candidate token IDs.
2. FROZEN_PROTOCOL.md, config.json and frozen_sources.json fix the hypotheses,
   local query positions, contrasts, controls, practical thresholds and budget
   before new model inference.
3. run_local.py validates original/restored numerics, collects discovery
   vectors, freezes one unscaled average, then scores every fixed fresh pair.
   Its interventions affect only numerical query positions L and L+1, not the
   whole-context projection edit. Full actual restoration is a separate
   denominator. All weights are restored and non-target tensors hashed.
4. analyze.py performs paired confirmation analysis; verify_finish.py checks
   raw histories, exact mean construction, random norms and device release.

The mean is pooled across discovery report sources/wordings/candidate histories;
no confirmation vectors enter it. Report/timer donors use identical numbers and
candidate suffixes, with matched lengths/positions. Their different action and
argument labels remain lexical/representational confounds for abstract semantic
interpretation. First numerical prediction and candidate-conditioned later
completion are reported separately. No generated-action prevalence is inferred
from supplied-prefix scores.

thermal_supervisor.py schedules cooling pauses for this exact owned local
worker. It changes no model input, vector, score or scientific source. The
separate A5000 experiment is peer-v7-block23-mediation and shares no GPU or
numerical pair with this study.
