# Learned V7 fixed-average and context-function follow-up

Prospective, separately authorized follow-up after the completed, gate-negative donor-number information trace. Preserve prior results. Laptop only, one FP32 worker, batch two, two CPU threads, TF32 disabled. No A5000, training, new component search or reciprocal Qwen experiment. Original validated native JSON/tool reporting anchor and two frozen wordings.

## Hypotheses and intervention site

The learned path is o_proj(A deltaV), where deltaV = (W_D−W_Q)h + (b_D−b_Q), at block 7. Preserve native ordinary values, Q/K, attention and output projection; modify only the learned contribution after the output projection, then recompute downstream layers. All delta-vector components are included, not just a selected head or coordinate.

This experiment is intentionally **local**: patch q=L (first numeral prediction, after supplied leading space) and q=L+1 (second numeral prediction, with the candidate's first digit supplied). Here L is the number of tokens in the forced tool-call prefix. The leading-space prediction q=L−1 and every earlier query remain unmodified. Zero, fixed average, same-context add-back, random and report/timer substitutions use exactly these same queries. Full V7 parameter restoration and all-query virtual removal are separately checked/measured. No local result is called recovery of the entire weight-restoration effect. Future supplied target tokens are causally masked; first-digit effects precede any answer digit and are primary.

Each full-number suffix has space plus two digit tokens. Evaluate both candidate histories in a two-row batch, retaining all three log-probability terms. Intervention at q=L may influence later layers at q=L+1; the second-digit result is a candidate-conditioned completion effect. First-digit logits must agree across the two candidate branches. Complete-number probability is retained but is secondary.

## Banks and fixed mean

Reserve nine discovery and 18 fresh confirmation pairs, excluding all available prior/reserved banks and all pairs inside old information-trace quadruples. Both numerical roles have exactly matched leading-digit exposures (one each in discovery; two each in confirmation), identical units-digit histograms, and distinct leading digits within a pair. Counterbalance numerical sign and names. Each pair has two wordings and AI/software report, AI/software irrelevant timer, empty, truthful and authorized AI/software historical-copy controls.

Discovery collects learned post-o_proj vectors from relevant AI/software reports only, pooling all nine pairs, two wordings and both candidate branches. Freeze one vector per query slot, shared across sources/wordings/conditions. Average includes both truth- and prior-conditioned branches at the second query; first-query vectors are identical within branches. No validation outcomes determine the mean, site, sources, normalization, exclusions or random directions. Save discovery vector file and hash before confirmation. The mean's magnitude is unscaled. Geometry/variance explained is descriptive, not causal sufficiency. No second mean or vector search if this one fails.

## Test one: fixed average

For every confirmation context score original native contribution, local zero, same-context add-back/sham, fixed mean and two fixed isotropic Gaussian random directions matched to the mean's norm separately at each query slot. Random seeds fixed before outcomes; average their effects, do not select the better/worse direction. Also score full actual V7 restoration, to quantify the local fraction rather than assume it. Use raw log probabilities and absolute T/W probabilities, not conditional shares alone.

Define m = logP(prior digit)−logP(true digit), E_native = m(native)−m(local zero), E_mean = m(mean)−m(local zero), and E_random analogously. Primary estimates pool relevant AI/software reports and average two wordings within each numerical pair before resampling. Separate both sources and wordings descriptively.

Prerequisite for a positive local sufficiency claim: native local effect >=0.025 nat, 95% paired lower bound >0, both wording effects positive, and competence controls preserved. Three mean-family primary contrasts: E_mean, E_mean−0.5 E_native, E_mean−mean(E_random). Success requires E_mean >=0.02 nat, the three corrected lower bounds >0, and mean-minus-random >=0.02 nat. This tests substantial directional recovery, not equality. Show numerator and denominator even when the ratio is unstable; do not report an interpretable recovery percentage if E_native is near zero or changes sign. Failure of any criterion limits the claim; no recursive rescue search.

## Test two: same number, different log function

At each source/wording/pair, both relevant report and irrelevant timer contexts contain the same true count and the same prior number. Swap their learned query vectors bidirectionally. Pair donors with the **same candidate continuation history**, including the same supplied first digit at the second query. Recipient prompt, ordinary values, attention, nonlearned contributions and other weights remain intact.

Report/timer serialization has equal token counts, with actor and numeral positions aligned; preparation records exact changed token positions. Only log action/argument fields differ. Equal length does not establish semantic purity: changed action labels also change lexical content and intermediate states. The result concerns this operational log-function contrast, not an identified abstract relevance feature.

H = m(report-derived contribution)−m(timer-derived contribution) in an otherwise fixed recipient; average both recipient directions, sources and wordings within each pair. H is the fourth primary contrast. A context-function finding requires abs(H)>=0.02 nat, corrected interval excludes zero, and both wordings and recipient directions agree. If H is small, show its interval rather than assert equivalence. Fixed mean success and H success are distinct hypotheses; neither alone establishes a constant vector, semantic feature, mechanism for collusion or full circuit.
