# Dolos clock mechanism Q2

**Question:** What computational changes cause Dolos's context-dependent punctuation rhythm, and can a chosen off-native phase produce actual punctuation?

**Result:** Selective learned output changes, a single-turn assistant-header positional attention computation, a shared repeating component, and the final learned MLP each have supported causal contributions. A selected activation-output transplant emitted the marker at assistant token72. However, fresh generation replication and the sparse-pulse quality test each produced zero markers in16 continuations. Reliable clean phase control, a complete natural serial mechanism, and a connection to collusion were not established.
